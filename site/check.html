Opsec Check About the project

Check a message in your browser

Experimental. This version doesn't work reliably on every laptop yet. If it fails, use the desktop version.

No install. The model downloads into this browser once, then runs on your own device. Messages you paste here are never sent anywhere.

This browser can't run Opsec Check

It needs WebGPU, which works in recent Chrome or Edge on a laptop or desktop. Try one of those, or install the desktop version instead.

Load the model (one time)

This downloads about 1 GB into your browser: a compressed 4-bit version of Qwen3.5-2B, the same open model as the desktop version. It takes a few minutes on a good connection. After that it loads from your browser in seconds and works offline.

Best on a laptop with 8 GB of memory or more. Phones and older machines may struggle.

Result

Read aloud by your device's own voice. Nothing is sent anywhere.

Opsec Check can be wrong. It never says a message is definitely safe. If in doubt, check through a channel you already trust.
